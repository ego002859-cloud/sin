# 신부장 콘텐츠 스튜디오

인스타 채널 운영판. 레퍼런스 조사 → 적용점 → 기획 → 발행 → 피드백 5단계를 한 화면에서 돌린다.
파일 하나로 동작하고, 구글 시트를 붙이면 여러 명이 같은 판을 함께 본다.

## 바로 쓰기

`index.html`을 브라우저로 열면 끝이다. 서버도 설치도 필요 없다.
이 상태에서는 **내용이 내 브라우저에만 저장된다.**

## 같이 쓰기 (구글 시트 연결)

1. 구글 시트를 새로 만든다
2. **확장 프로그램 → Apps Script**에 `sheet_api.gs` 내용을 붙여넣는다
3. **`setup()` 을 한 번 실행**한다
   - 시트 3개(`refs` / `posts` / `meta`)가 생긴다
   - 실행 로그에 **ACCESS KEY**가 찍힌다 — 복사해 둔다
4. **배포 → 새 배포 → 웹 앱**
   - 실행: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 주소(`.../exec`)를 복사한다
5. 대시보드 상단 **공유** 버튼 → 주소와 ACCESS KEY 입력

같은 주소·키를 넣은 사람끼리 같은 판을 본다.

### 무엇이 공유되나

| 공유됨 | 공유 안 됨 |
|---|---|
| 레퍼런스, 기획, 성과 수치 | 지금 보고 있는 단계 |
| 채널 아이덴티티, 목표 | 필터, 펼쳐 둔 훅 템플릿 |
| 메모 | 인스타 동기화 주소 |

화면 상태까지 공유하면 남이 탭을 바꿀 때마다 내 화면이 따라 움직여서 같이 못 쓴다.

### 상태 표시

상단 **공유** 버튼 색으로 확인한다.

- 🟢 **연결됨** — 시트에 저장되고 있다
- 🟡 **저장 중** — 올리는 중 (구글 시트 왕복은 5~8초 걸린다)
- 🔴 **연결 끊김** — 이 브라우저에만 저장된다. 연결이 돌아오면 다시 올라간다

인터넷이 끊겨도 작업은 계속된다. 로컬에 먼저 쓰고 시트에 올리는 구조다.

### 충돌

두 사람이 동시에 고치면 나중 사람이 앞사람 작업을 지운다.
그래서 저장할 때 버전을 확인하고, 어긋나면 멈추고 물어본다.

- **확인** — 상대방 내용을 불러온다 (내 최근 변경은 사라진다)
- **취소** — 그대로 두고 백업 파일로 내보낸다

조용히 덮어쓰지 않는다.

## 레퍼런스 등록

- **한두 개** — 레퍼런스 단계에서 `+ 추가`
- **조사분 통째로** — `조사분 가져오기`. `bm_import.json`을 읽어 라운드를 고르면, **아직 없는 계정만** 들어온다. 기존 내용은 그대로 둔다

`bm_import.json`이 `index.html`과 같은 폴더에 있으면 자동으로 읽는다. 없으면 파일 선택창이 뜬다.

## 인스타 지표 자동 입력 (선택)

`ig_sync.gs`는 별개다. 인스타 프로 계정과 Meta 앱 토큰이 있어야 동작한다.
붙이면 게시물 링크가 입력된 콘텐츠의 조회·좋아요·댓글·저장과 팔로워 수가 자동으로 채워진다.
훅·대본 같은 사람이 쓴 내용은 건드리지 않는다.

**채널 개설 전에는 넣을 게 없다.** 계정을 만든 뒤에 붙이면 된다.

## 백업

`백업` 버튼으로 JSON을 받아둘 수 있다. `복원`으로 되돌린다.
시트를 쓰더라도 중요한 시점에는 백업을 받아두는 편이 안전하다.

## 파일

| 파일 | 용도 |
|---|---|
| `index.html` | 대시보드 본체. 이거 하나만 있어도 동작한다 |
| `sheet_api.gs` | 구글 시트 저장소 (같이 쓰기용) |
| `ig_sync.gs` | 인스타 지표 수집 (선택) |
| `bm_import.json` | 조사 라운드 누적 파일 |

## 주의

**접근키를 저장소에 올리지 말 것.** 키는 각자 브라우저에만 저장되고 `index.html`에는 들어 있지 않다.
URL과 키를 아는 사람은 누구나 시트를 읽고 쓸 수 있다. 유출되면 `setup()`을 다시 실행하면 키가 바뀐다.

**공개 저장소에 올리면 `index.html` 안의 채널 전략이 그대로 공개된다** —
훅 템플릿 20개, 포지셔닝, 타겟, 목표 수치. 경쟁자가 복사할 수 있는 자산이라면 비공개 저장소를 쓰거나 파일을 직접 전달하는 편이 낫다.
